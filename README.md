A deterministic Python program that writes one funny single-line excuse a developer gives when code breaks in production — at most 200 characters — to /output/entry.txt. The excuse: the developer approved their own pull request at 2 a.m., and the only reviewer awake was them, asleep.

## Run it

```sh
python3 main.py
```
